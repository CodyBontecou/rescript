# App Store assets

Canonical App Store marketing screenshots live in `screenshots/<locale>/`.

The English set is ordered for upload by its numeric filename prefix:

1. Edit video by editing words
2. Transcribe on-device
3. The transcript drives the cut
4. Follow every speaker
5. Export the finished cut

All screenshots are flattened RGB PNGs at 1320×2868 pixels for the iPhone 6.9-inch display class.
